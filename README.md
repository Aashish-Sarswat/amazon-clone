# Amazon Clone 

A frontend clone of the Amazon website
built using HTML and CSS.

##  About the Project

This project is created to practice frontend
web development concepts and improve my
HTML and CSS skills.

##  Technologies Used

- HTML5
- CSS3
- Font Awesome

##  Features

- Navigation Bar
- Amazon-style Search Bar
- Delivery Location Section
- Product Categories
- Hero Banner
- Product Cards
- Footer Section

##  Project Structure

- index.html
- style.css
- amazon_logo.png
- hero_image.jpg
- box1_image.jpg to box8_image.jpg

##  What I Learned

- HTML page structure
- CSS styling
- Flexbox
- Navigation bar design
- Working with images and icons
